# Krishna 3D Portfolio

A Bruno-Simon-inspired interactive portfolio built with React, React Three Fiber, Three.js, Framer Motion and Vite.

## Run
1. Install Node.js 20.19+.
2. Open this folder in a terminal.
3. `npm install`
4. `npm run dev`
5. Open the URL printed by Vite.

## Customize
Edit `src/main.jsx`, especially the `DATA` object.
- Projects
- GitHub / LinkedIn / LeetCode / Kaggle
- Resume
- Email
- Skills

Replace `public/resume.pdf` with your real resume.

## Controls
- WASD / arrow keys: move the 3D vehicle
- Mouse/touch drag: orbit the camera
- Scroll: zoom

This is an original implementation inspired by interactive 3D portfolio patterns, not a copy of another site's source code.
